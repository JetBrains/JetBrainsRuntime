# Text rendering scene

A small project for the **Skia backend** text comparison: an editor file with *keywords*, comments,
strings and `ligatures`, this Markdown preview, and a terminal.

- Inter for the UI, JetBrains Mono for the editor
- LCD and grayscale anti-aliasing
- 100 %, 150 % and 200 % scale
